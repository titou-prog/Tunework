# Tunework 🎶

Mini-jeux pour apprendre à **chanter juste** : c'est la justesse de la voix (micro de l'iPad ou de l'ordinateur) qui fait gagner. Style anime / manga.

**Ouvrir l'appli : https://titou-prog.github.io/tunework/**

## Les modes
- **L'Envol de Sora** : l'hirondelle suit la hauteur de ta voix pour traverser les anneaux.
- **La Plongée de Kai** : le dauphin nage entre les rochers ; tiens la bonne note pour rester dans le passage.
- **Le Sceau de Kitsune** : écoute la note de l'esprit farceur, puis tiens-la juste pour le sceller.
- **L'Écho des Étoiles** : écoute une courte mélodie, puis rechante-la note après note.
- **Les Lanternes du Festival** : chante la note d'une lanterne pour l'allumer avant qu'elle s'envole.
- **L'Ascension d'Usagi** : chante la gamme marche après marche jusqu'à la lune, puis redescends.
- **Le Dragon et la Perle** : fais glisser ta voix (sirène) pour suivre le ruban doré et gober les perles.
- **Le Dojo de la Voix** : entraînement libre, voix affichée en direct.

## Réglages
Tessiture (préréglages ou mesure au micro), difficulté (tolérance ±50 / ±35 / ±22 cents), octave libre (voix qui muent), note guide, notation Do Ré Mi (La3 = 440 Hz) ou C D E, sensibilité du micro.

## Remarques
- Le micro ne fonctionne que sur une adresse **https** (GitHub Pages convient).
- Fichier unique `index.html` (HTML, Tailwind CSS, JavaScript). Une connexion internet est nécessaire pour le style et les polices.
