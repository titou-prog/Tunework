# Tunework 🎶

Mini-jeux pour apprendre à **chanter juste** : c'est la justesse de la voix (micro de l'iPad ou de l'ordinateur) qui fait gagner. Style anime / manga, pour les 11-15 ans.

**Ouvrir l'appli : https://titou-prog.github.io/Tunework/**

## Progression
- **5 niveaux par jeu** : la marge de justesse se resserre (±60 → ±22 cents), les intervalles s'agrandissent (notes voisines → sixtes), la vitesse augmente, les notes à tenir s'allongent ; au niveau 5, les noms de notes sont parfois cachés.
- Un niveau se débloque en obtenant au moins **B** au précédent (option « Tous les niveaux débloqués » pour le professeur dans les réglages).
- **Notes différentes à chaque partie** : mélodies tirées au hasard et tonalité au hasard (Do, Sol, Fa, puis Ré et Si♭ majeur à partir du niveau 3).

## Réglages
Tessiture (préréglages ou mesure au micro), octave libre (voix qui muent), note guide, notation Do Ré Mi (La3 = 440 Hz) ou C D E, sensibilité du micro, volume, diagnostic du son.

## Remarques
- Le micro ne fonctionne que sur une adresse **https** (GitHub Pages convient).
- Fichier unique `index.html` (HTML, Tailwind CSS, JavaScript). Une connexion internet est nécessaire pour le style et les polices.
